# Stable-version reference

## European Captives v1.2

**Status:** stable baseline; do not modify as part of the North African/Ottoman map development.

The stable version’s approved characteristics include:

- established historical-atlas palette, typography, layout, and navigation;
- OpenStreetMap basemap;
- search, date filtering, Reset Filters, and a short how-to guide;
- complete access to all 3,137 records, including a No Location Data view;
- documented connections enabled by default;
- map options ordered Both, Origins, Captivity, No Location Data;
- nine-field historical records: Name, Place of Origin, Place of Captivity, Convert, Date, Ship Name, Source, Notes, Record ID;
- date-method note beneath the Date field;
- one complete CSV download.

## Change policy

Treat v1.2 as a reference design and rollback point. Changes to that application should be limited to:

- verified data corrections;
- accessibility defects;
- security or dependency maintenance;
- browser-compatibility defects;
- documentation clarifications.

Collection-specific experimentation belongs in the companion application. Do not back-port its Papal Period filter, two-name layout, origin-only semantics, or inferred-period logic to the stable European map unless a separate research and usability review justifies the change.
